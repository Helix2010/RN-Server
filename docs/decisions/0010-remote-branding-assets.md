# ADR-0010：租户品牌与启动资源

状态：Accepted（2026-08-29）

## 决策

- 启动页品牌配置使用 `app_configs.config_key='branding'`，不新增资源业务表；图片二进制进入现有租户对象存储。
- 上传采用临时资源票据，只有对象存在、大小和图像格式校验通过后才允许写入租户配置。
- 读取按域名解析租户，配置按字段合并：租户覆盖全局，未覆盖字段继承全局。
- 文案继续由 `language_document` 管理，branding 只保存 `launch.titleKey/subtitleKey`，语言目录动态读取 `app_configs.languages`。
- 移动端返回当前语言和当前配置所需的解析结果，并通过不可变资源 ID 提供下载；客户端完成哈希校验后原子缓存。

## 非目标

- 不通过远程配置替换 Android/iOS 系统桌面图标、Adaptive Icon 或原生启动屏；这些仍需全量构建。
- 不下发任意 JavaScript、SVG 脚本或动态页面代码；动画只能使用客户端内置枚举。

## 回滚

管理员暂停或改回上一份 branding 配置；客户端下载失败自动使用上一有效缓存或 APK 内置资源。未被配置引用的对象交由后续生命周期清理，不在发布事务中删除。
